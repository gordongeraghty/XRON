## 2024-05-14 - Skip to Main Content Accessibility
**Learning:** React single-page applications often lack a native way for keyboard and screen reader users to bypass repetitive navigation elements. Without a skip link, users must tab through the entire header/navigation on every page view.
**Action:** Always implement a visually hidden "Skip to main content" link at the top of the DOM that becomes visible on focus. Ensure it targets the main content area using an `id` and `tabIndex={-1}` to correctly move focus without adding the container itself to the natural tab sequence. Use `focus:outline-none` on the target to avoid drawing an outline around the whole content area when programmatic focus is applied.
