## 2024-05-17 - Improve Empty State with Call-to-Action
**Learning:** In multi-select components like format toggles, leaving a blank or basic text-only empty state when all options are disabled provides a poor experience, leaving the user without an immediate path to recovery.
**Action:** Always implement a visually structured empty state that includes a clear call-to-action button (like "Reset to defaults") to give users an immediate way to recover from an empty state.
