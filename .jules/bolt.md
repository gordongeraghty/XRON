## 2024-06-06 - Avoid string spreading [...str] for surrogate-aware unicode operations
**Learning:** In hot path string operations like `longestCommonSuffix`, spreading strings to arrays using `[...s].reverse()` completely bypasses native string optimizations in JS engines, turning a simple O(N) traversal into an allocation-heavy operation. The old version took ~380ms for 100 iterations of 1000 strings.
**Action:** Instead of allocating arrays and reversing, use strict `charCodeAt` index loops (`first.charCodeAt(first.length - 1 - j)`). To safely handle UTF-16 surrogate boundaries (emojis), detect if the loop split on a high surrogate (`>= 0xD800 && <= 0xDBFF`) when matching prefixes or a low surrogate (`>= 0xDC00 && <= 0xDFFF`) when matching suffixes, and manually back off by 1 code unit. This drops execution to ~20ms while remaining unicode-safe.
