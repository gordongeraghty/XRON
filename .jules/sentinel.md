## 2024-05-24 - [Fix Prototype Pollution in XRON Parser]
**Vulnerability:** A prototype pollution vulnerability allowed attackers to execute prototype pollution attacks by crafting specific XRON payloads containing `__proto__`, `constructor`, or `prototype` keys. This was possible via two attack vectors: inline arrays and objects, and fallback to `JSON.parse` with subsequent object parsing.
**Learning:** Even custom parsers can be vulnerable if they do not explicitly block properties that manipulate prototypes during object creation, and `JSON.parse` can also return objects with these keys, which when merged or accessed unsafely, result in prototype pollution.
**Prevention:** Block specific property names (`__proto__`, `constructor`, `prototype`) during object property assignment logic. Furthermore, hook `JSON.parse`'s reviver to ignore these properties entirely when parsing JSON representations of objects to ensure nested payloads also don't carry the properties over into the system.
